# README — Second Nature web

Early restyle of [usalproject.com](https://www.usalproject.com/) structure under the **Second Nature** brand deck.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — routes `/` and `/shop`.

## What mapped

| Usal structure | Second Nature |
| --- | --- |
| Full-bleed hero + floating nav + cart | Same chrome, SN voice & tokens |
| Events directory list | Pathways index |
| Shop grid + filters + cart | Protocols catalog + stub cart |
| Status strip / newsletter / mega mark | Rewritten utility footer |

Design tokens and gap notes: `docs/restyle/second-nature/`.
