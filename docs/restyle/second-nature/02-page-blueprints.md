# Page blueprints

## Home (`/`)

Order (top → bottom):
1. Nav/Global — logo, circle-marker links, hard-rect Log In / Cart; mobile menu
2. Hero/FullBleed — lifestyle media + ambient drift, brand line, one Shop CTA, status strip bottom-left
3. Index/Pathways — oversized left-aligned list with [counts] over blurred motion plate
4. Philosophy/Pillars — deck p5 asymmetry: tall portrait ~1/3 + massive “Core Philosophy” + 3 columns with numerals at base
5. Community/Proof — forest flood immersion + documentary image strip
6. Field Notes — editorial journal strip (Science trust)
7. Opportunity split — macro plate + quiet CTA (pollen)
8. Marquee — optional ambient (shipping / feeling)
9. Footer — newsletter, links, mega SECOND NATURE wordmark

Primary action: Shop CTA in hero  
Secondary: Pathways → shop filtered views (stub)

## Shop (`/shop`)

Order (top → bottom):
1. Nav/Global
2. Title/Shop — oversized page title
3. Filter/Bar — Show Filters (Meet the family → category pages)
4. Grid/Product — lookbook, edge-to-edge 3-col; name + [$price]; tile → PDP (not cart drawer)
5. Newsletter (via footer)
6. Footer
7. Cart/Drawer — only from Cart control or PDP Add to cart; pollen checkout confirm only

## Category family (`/shop/{recovery|performance|sleep|foundation}`)

Order (top → bottom):
1. Nav/Global
2. Breadcrumb + oversized family title + poetic dek
3. Split editorial plate — lifestyle hero + tagline / description / focus list + status
4. Protocols grid — products in family (same lookbook tiles → PDP)
5. Other pathways index — Usal-style list with [counts]
6. Footer

## Product PDP (`/shop/{product-id}`)

Pattern: Usal `/shop/[slug]` + Leif/Abel editorial apothecary
1. Nav/Global
2. Breadcrumb Shop / Family / Product
3. Split: large image plate (+ gallery thumbs) | mono family · display name · [$price] · serif blurb · body · hairline specs · pollen Add to cart
4. Accordion: Protocol + Field notes
5. Same-family related grid
6. Footer
7. Cart/Drawer opens only after Add to cart
